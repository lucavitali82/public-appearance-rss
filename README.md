# Public Appearance RSS Monitor

RSS 2.0 feed for upcoming public appearances and events in Italy featuring the monitored public figures.

## Feed

Once GitHub Pages is enabled, the feed will be available at:

https://lucavitali82.github.io/public-appearance-rss/feed.xml

## Notes

- Add events only when supported by source evidence.
- Distinguish event dates from article publication dates.
- Mark admission as free, paid, or unknown.
- Keep unverified leads separate from confirmed events.
- This repository contains public feed data only. Never commit credentials, private monitoring code, or personal email addresses.
